## Как подготовить снимок

Выберите чёткое изображение лица без сильных фильтров и обрезки. Проверьте, что на фото один человек. Для собственного профиля можно взять снимок, который уже опубликован вами. Не загружайте чужие личные фотографии из закрытой переписки.

Если бот принимает фотографию, отправьте её в соответствующий режим поиска. Доступность функции и состав ответа могут меняться. При совпадении могут появиться похожие страницы соцсетей или связанные записи, но их нужно проверить вручную.

## Как понять результат

Откройте найденный профиль и сравните дату публикации, другие фотографии, ник и публичные сведения. Репост и исходная страница могут выглядеть одинаково, поэтому полезно найти первоисточник снимка. Сходство лица может быть случайным; разные фотографии одного человека тоже выглядят по-разному.
